O primeiro projeto do curso de banco de dados da faculdade de ADS da Unoesc Chapecó/SC
Sistema de Votação para Eleições

 Sobre o projeto

Este projeto foi desenvolvido como atividade acadêmica da disciplina de Modelagem de Banco de Dados e Linguagem SQL, do curso de Análise e Desenvolvimento de Sistemas (ADS).
O trabalho consiste na modelagem e criação da estrutura inicial de um banco de dados para um sistema de votação eleitoral, utilizando MySQL.

Objetivo

O objetivo é aplicar os conceitos de modelagem de dados e linguagem SQL, organizando as informações de eleitores, candidatos, partidos, cargos e votos.
O sistema foi estruturado para registrar os votos dos candidatos sem estabelecer uma ligação direta entre o eleitor e seu voto, respeitando o princípio do sigilo eleitoral.

Tecnologias utilizadas

MySQL
MySQL Workbench
SQL

Conhecimentos aplicados

Modelagem de banco de dados relacional
Criação de tabelas
Chaves primárias e estrangeiras
Relacionamentos entre tabelas
Comandos SQL (DDL e DQL)

Finalidade

Projeto desenvolvido para fins acadêmicos e de aprendizado, com o objetivo de fortalecer os conhecimentos iniciais em banco de dados e desenvolvimento de sistemas.
